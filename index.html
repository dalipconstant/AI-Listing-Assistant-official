Setup — API key (once)

  1. Install AI Listing Assistant from the Chrome Web Store and pin it.
  2. Open the extension → Settings (gear icon).
  3. Choose engine (Gemini recommended for free) and paste your API key.
  4. Click Test connection and wait for the green tick.
  5. Optional: use Get free Gemini API key → opens Google AI Studio → create key → paste back.
Free Gemini key: aistudio.google.com/api-keys

How to use

  1. Open a product edit page on Meesho Supplier or Flipkart Seller Hub (with product images uploaded).
  2. Click the extension icon.
  3. (Optional) Add competitor product links and choose a seller tone.
  4. Click AI Listing / Start and wait for the result.
  5. Review title, description and other fields. Edit if needed.
  6. Click Autofill — fields fill step by step. Submit the listing yourself on the marketplace.
Always double-check AI text before publishing. We do not guarantee ranking or order increases. Content is AI-assisted and may need human review.
